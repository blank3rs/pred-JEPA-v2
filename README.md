# JEPA-v2: Joint Embedding Predictive Architecture Implementation

This project implements a Joint Embedding Predictive Architecture (JEPA) using a pre-trained transformer model (RoBERTa-base) as the backbone. The goal is to learn meaningful representations by predicting the embeddings of masked portions of a sequence from the embeddings of unmasked portions.

## Key Features

*   **Shared Encoder:** Uses a `roberta-base` model as the core encoder.
*   **Momentum Target Encoder:** Employs a momentum-updated target encoder to generate stable target representations, inspired by self-supervised methods like MoCo and BYOL.
*   **Embedding-Level Masking:** Masks input tokens at the embedding level using a learnable mask embedding, rather than replacing input IDs.
*   **Predictor Network:** A separate network predicts the target representation from the context representation.
*   **Energy-Based Loss:** Utilizes an energy-based loss function (inspired by JEPA) combined with an InfoNCE-style loss for training, comparing predicted targets with actual targets and negative samples.
*   **Learnable Temperature:** Includes a learnable temperature parameter for the InfoNCE loss calculation.

## Usage

Instantiate the `JEPAEncoder` and use it to process your input data.

```python
import torch
from jepa_encoder import JEPAEncoder

# Example Usage
model = JEPAEncoder(hidden_size=768, projection_dim=256)
model.train() # Set to training mode

# Dummy data (replace with your actual data loader)
batch_size = 4
seq_len = 128
input_ids = torch.randint(0, 30522, (batch_size, seq_len)) # Example vocab size
attention_mask = torch.ones(batch_size, seq_len, dtype=torch.long)

# Create a mask for positions (e.g., mask 40% of tokens)
mask_prob = 0.4
is_masked_positions = torch.rand(batch_size, seq_len) < mask_prob

# Forward pass
output = model(input_ids, attention_mask, is_masked_positions)

# Access outputs
loss = output['energy_loss']
print(f"Loss: {loss.item()}")

# Backpropagation (in a training loop)
# loss.backward()
# optimizer.step()
# optimizer.zero_grad()

# For evaluation
model.eval()
with torch.no_grad():
    eval_output = model(input_ids, attention_mask, is_masked_positions)
    # Analyze eval_output metrics like cosine similarity, L2 distance, etc.
```

## Training

The model is trained to minimize the energy-based loss between the predicted target embeddings and the actual target embeddings (generated by the momentum encoder). Negative samples (other examples within the batch) are used to prevent representational collapse.

## Model Details

*   **Base Transformer:** `roberta-base`
*   **Projection Dimension:** Configurable (default: 256)
*   **Momentum:** Configurable (default: 0.999)
